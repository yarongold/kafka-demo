# kafka-demo

A self-contained Kafka demo for local OpenShift. Produces orders, consumes them, scales consumer groups, and routes bad records to a DLQ — with a Kafka UI for visualization.

See [docs/superpowers/specs/2026-05-20-kafka-openshift-demo-design.md](docs/superpowers/specs/2026-05-20-kafka-openshift-demo-design.md) for the design.

Install instructions, exercises, and uninstall steps will be filled in as the implementation lands.
